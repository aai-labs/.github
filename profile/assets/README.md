# Profile artwork

The header uses AAI Labs' existing wordmark, sourced from `aai-labs/Tickmark/assets/logo/aai-labs-logo-{blue,white}.svg`, with a small terminal-and-connections illustration made for this profile. Separate light, dark, and mobile versions keep the wordmark and caption readable.

Project artwork is copied from the public repositories so the organisation profile does not depend on their asset paths:

- `agent-barn.webp`: `aai-labs/agent-barn/.github/assets/agent-barn-logo.webp`.
- `tickmark.svg`: `aai-labs/Tickmark/assets/logo/tickmark-app-icon.svg`.
- `aai-cli.svg`: a simple terminal symbol made for the profile; not a replacement product logo.

Images in the profile use absolute raw GitHub URLs because the README is also displayed on the organisation overview.
